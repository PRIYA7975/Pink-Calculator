# Pink Calculator

## About the Project

Pink Calculator is a simple and user-friendly calculator application developed using HTML, CSS, and JavaScript. It provides a clean interface with a soft pink theme and allows users to perform basic mathematical calculations.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Decimal number support
- Clear and delete functionality
- Responsive user interface

## Project Structure


Pink-Calculator/
├── Calculator.html
├── Calculator.css
├── Calculator.js
└── README.md


## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `Calculator.html` in your browser.
4. Start performing calculations.
